## Preparo para entrevista e modelos

Se eu estiver especificamente treinando para entrevistas, o Galego passou uma lista para estudar dentro de cada estrutura de dados.

### Estruturas

- Array
- Linked list
- Stack
- Queue
- Binary tree
- Graph
- Hashmap / hashtable

### Problemas

- Two pointer
- Slide window
- Backtracking
- DFS
- BFS
- Binary search
- DP (dynamic programming)
- Sorting
- Bit manipulation
- Matrix

### 2 formas de aprender que o Galego ‘freezou’

- Prática deliberada
    
    Propositalmente tentar entender algo que está no limite da sua capacidade. Nem difícil de mais (pra você não se desmotivar desistir) e nem fácil de mais (para você não se folgar e largar mão).
    
- Repetição espaçada
    
    Resolver problemas com um certo espaçamento de tempo. É literalmente prática deliberada com constância até a fixação de resoluções.
    

## Resumo

Entenda uma estrutura

Entenda os exercícios dessas estruturas

Pratica hoje, daqui uma semana, etc.

> Quase garantidamente se dará bem numa entrevista.
