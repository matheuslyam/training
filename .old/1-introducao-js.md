## o que é JavaScript e para que serve

JavaScript é uma linguagem de programação que permite criar conteúdo dinâmico e interativo em páginas web.
Ele é usado para adicionar funcionalidades, manipular elementos HTML, responder a eventos do usuário e muito mais.
JavaScript é essencial para o desenvolvimento web moderno, permitindo que os sites sejam mais do que apenas páginas estáticas.

## onde o JavaScript é utilizado

JavaScript é amplamente utilizado em navegadores para criar experiências interativas para os usuários.
Ele também é usado no lado do servidor com plataformas como Node.js, permitindo que os desenvolvedores criem aplicativos completos
usando JavaScript. Além disso, JavaScript é utilizado em desenvolvimento de aplicativos móveis, jogos, automação e muito mais.

## como adicionar JavaScript a uma página HTML

Existem três maneiras principais de adicionar JavaScript a uma página HTML:

1. Inline: Usando o atributo `onclick` ou outros eventos diretamente em elementos HTML.
2. Interno: Colocando o código JavaScript dentro de uma tag `<script>` no corpo ou na cabeça do documento HTML.
3. Externo: Criando um arquivo JavaScript separado (por exemplo, `script.js`) e vinculando-o à página HTML usando a tag `<script src="script.js"></script>`.
4. A abordagem externa é a mais recomendada para manter o código organizado e reutilizável.
5. Existe mais maneira de adicionar JavaScript, como frameworks e bibliotecas, mas as três mencionadas são as formas básicas e mais comuns.

## ferramentas essenciais

Ferramentas essenciais para o desenvolvimento com JavaScript incluem:

- Um navegador web moderno (como Chrome, Firefox ou Safari) com dev tools ativados.
- Um editor de código (como VS Code, Sublime Text ou Atom).
- Um terminal ou console para executar comandos e depurar o código.
Essas ferramentas permitem que os desenvolvedores escrevam, testem e depurem seu código JavaScript de maneira eficiente.
